# SIERCP API Reference

This document outlines the internal Next.js API routes used by the SIERCP LMS multi-tenant platform.

## Base URL
All API requests are relative to the deployment URL (e.g., `https://siercp.com/api`).

---

## 1. Enrollment API

### `POST /api/enrollment`
Processes a student enrollment, handles Wompi payment completion, triggers cohort automation, and sends email notifications.

**Request Body (JSON):**
```json
{
  "email": "student@example.com",
  "nombre": "Juan Perez",
  "telefono": "+573000000000",
  "cursoSlug": "soporte-vital-basico",
  "cohortId": "ch_123456",
  "templateId": "tpl_123456",
  "institutionId": "inst_123456",
  "paymentId": "pi_wompi_abc123",
  "paymentMethod": "CARD",
  "amountPaid": 150000
}
```

**Response (200 OK):**
```json
{
  "success": true,
  "isNewUser": true,
  "userId": "user_123",
  "enrollmentId": "enr_123",
  "automationTriggered": false,
  "credentials": {
    "email": "student@example.com",
    "tempPassword": "AutoGenerated123",
    "message": "Cuenta creada en SIERCP. Usa estas credenciales para acceder."
  }
}
```

## 2. Admin Courses API

### `POST /api/admin/courses`
Creates a new course template for an institution.

**Request Body (JSON):**
```json
{
  "title": "Soporte Vital Básico",
  "slug": "soporte-vital-basico",
  "institutionId": "inst_123456",
  "settings": {
    "level": "Básico",
    "modality": "Híbrida",
    "priceCOP": 150000
  },
  "modules": [
    {
      "id": "mod_1",
      "title": "Introducción",
      "duration": 60,
      "order": 0
    }
  ]
}
```

**Response (200 OK):**
```json
{
  "success": true,
  "templateId": "tpl_123456"
}
```

---

## 3. Automation API

### `GET /api/cron/check-cohorts`
Cron job endpoint (invoked hourly by Vercel) that sweeps the database for cohorts that need to be automatically opened or closed based on their schedule or capacity. Requires a valid `CRON_SECRET` authorization header.

**Headers:**
```
Authorization: Bearer <CRON_SECRET>
```

**Response (200 OK):**
```json
{
  "success": true,
  "processedCount": 12,
  "newCohortsGenerated": 2
}
```

---

## 4. Seed API (Development/Setup Only)

### `POST /api/seed/jomar`
Populates the Firestore database with initial Super Admin structures, Institution records (e.g. Jomar Seguridad), and default Plans.

**Response (200 OK):**
```json
{
  "success": true,
  "message": "Seeded successfully",
  "institutionId": "jomar_123"
}
```

## Error Handling
All APIs return standardized error responses on failure:

```json
{
  "error": "Mensaje de error descriptivo",
  "details": "Opcional, detalles técnicos"
}
```
* **400 Bad Request:** Missing required fields or invalid data formats.
* **401 Unauthorized:** Invalid session token or missing Cron secret.
* **409 Conflict:** Resource already exists (e.g. user already enrolled in cohort).
* **500 Internal Server Error:** Unexpected backend failures.
